# 单人斗地主

离线可玩的单文件浏览器斗地主：一名玩家对两名 AI。为手机竖屏设计，可安装到主屏幕，断网也能玩。

## 玩

打开 GitHub Pages 网址即可。手机上建议「添加到主屏幕」，之后点图标就能进，不联网也能开局。

- iPhone：Safari 打开 → 分享 → 添加到主屏幕
- Android：Chrome 菜单 → 安装应用 / 添加到主屏幕

本地直接双击 `index.html` 也能玩，只是 Service Worker 不会注册（离线缓存需要 http/https）。要完整测试离线安装：

```bash
python -m http.server 8123
```

然后访问 `http://localhost:8123/`。

## 操作

- 点一下选中 / 取消一张牌
- **按住横向滑过多张牌可以连续多选**（手机上比逐张点快得多）
- 键盘：`Enter` 出牌 · `空格` 不出 · `H` 提示 · `T` 托管

## 规则

54 张牌，你 + 2 名 AI，每人 17 张，底牌 3 张归地主。支持单张、对子、三张、三带一 / 带对、顺子（≥5 张连续）、连对（≥3 对连续）、飞机（连续三张，可带翅膀）、炸弹、火箭。除炸弹和火箭外，必须同牌型、同张数才能比大小。

## 积分

三个座位各有一份积分，初始 1000，跨局累计并存在本地。每局结算：

```
一份 = 底分 × 叫分 × 2^(炸弹+火箭数) × 春天倍数 × 地主反加倍 × 该农民的加倍
```

- **底分**：菜单里选（1 / 5 / 10 / 20 / 50），改动下一局生效 —— 已经开打的这局赌注是锁定的
- **叫分**：本局叫到地主的分数（1~3）
- **炸弹 / 火箭**：每出现一次翻一倍，谁出的都算；四带二不算
- **春天**：地主走完而两名农民一张没出，×2；农民走完而地主只出过第一手（反春天），同样 ×2
- **加倍**：见下

地主**分别**和两名农民各结算一份，所以地主赢收两份、输付两份，农民各收付一份。

顶栏实时显示你的积分和本局倍数（炸弹翻倍时会闪一下），每局结束的结算面板会摊开倍数是怎么乘出来的。积分允许为负，菜单里有「重置为 1000」。

## 加倍

定完地主、开打之前有一个加倍阶段：

1. 两名农民依次决定加不加倍。**农民的加倍只作用在自己那一份上**，两家各算各的
2. 地主看到农民的选择后决定要不要反加倍，**反加倍对两家同时生效**

所以两名农民的赌注可以不一样 —— 结算面板在这种情况下不显示「统一的一份」，改成每行标各自的变动。AI 按手牌强度决定加不加倍，地主门槛更高（它多了 3 张底牌），农民已经加倍时地主会更谨慎。

## 记牌器

花 500 积分一次性解锁，之后在设置里自由开关。开启后牌桌底部显示一条 15 格的计数条，是**两名对手手里**各点数还剩几张（打光的压暗，满 4 张的标金色）。

这条信息等于「总数 − 已打出的 − 我手里的」，全是公开信息、人自己也能记，所以实现上直接从对手手牌数出来 —— 和推算结果完全等价，而且刷新恢复后不用额外存已出牌的账。

## AI 性格

两个对手各有一种性格，名字按性格分池 —— 「疯狗」一定是莽的，「扫地僧」一定是稳的，名字本身就是打法的预告。头像里的字就是性格标记，长按能看到说明。

| 性格 | 叫地主 | 平均叫分 | 加倍 | 只能靠炸弹压时真的炸 |
| --- | --- | --- | --- | --- |
| 莽（激进） | 92% | 1.87 | 82% | 88% |
| 阴（阴狠） | 65% | 1.54 | 39% | 22% |
| 稳（稳健） | 52% | 1.44 | 2% | 53% |
| 咸（佛系） | 27% | 1.32 | 0% | 35% |

（中等难度下各 800 手随机牌实测。）

性格作用在三个地方：叫分门槛（`bidBias`）、加倍门槛（`doubleBias`）、以及**为了压一手牌值不值得动炸弹**（`bombReluctance`）。最后一条单独拎出来做判断，是因为放在候选打分里没用 —— 有普通牌能压的时候，炸弹本来就排在最后，调权重改变不了结果；真正的分歧只发生在「除了炸没别的能压」的时候。

对手是持久的，一直是这两位，直到你在设置里点「换一批对手」（打牌途中不给换）。积分记在他们身上，所以「赢了疯狗 300 分」这句话才有意义。

每种性格有自己的一套台词，在叫分、加倍、炸弹、不出、报单、胜负时触发，受话痨程度和每人 3 秒冷却限制 —— 一局大概 8 句，不会刷屏。台词气泡和牌型气泡是两种样式，不会混淆。

## 项目结构

全部代码内联在单个 `index.html` 里，不依赖构建工具、包管理器或任何外部 CDN。

```
index.html            页面 + 样式 + 全部游戏逻辑
manifest.webmanifest  PWA 清单（安装到主屏幕）
sw.js                 Service Worker（离线缓存）
icons/                应用图标
```

`index.html` 内部的分层，自上而下、后面依赖前面：

| 段落 | 职责 |
| --- | --- |
| `CONFIG` / `Deck` | 牌堆与常量 |
| `State` | 唯一的全局 `state` + localStorage 快照 |
| `Rules` | 牌型识别、比大小、候选枚举、手牌估值（纯函数，不碰 DOM） |
| `AI` | 叫分与出牌决策 |
| `Flow` | 发牌 / 叫分 / 回合循环（async，带 generation 防串场） |
| `UI` | 渲染、卡面、手牌布局、手势多选、浮层 |
| `Boot` | 音效、初始化、SW 注册 |

约定：任何改动 `state` 的地方，结束时调用 `saveState()` + `render()`。

## 开发笔记

- **卡面**：角标 + 3 列 × 7 行的经典点数排布，JQK 是带对角描金的花牌，大小王竖排。卡内所有尺寸用 `em` 相对 `--cw`（卡宽），整体等比缩放。
- **手牌布局**：`--cw` 和 `--overlap` 由 JS 按可用宽度和张数算出。超过 11 张自动分两行 —— 单行会把卡压到 44px，牌面就看不清了。
- **滑动多选**：`.hand` 用 `touch-action:none`，滑动手势留给多选而不是浏览器滚动；布局算法保证 320px 宽 / 20 张牌也放得下，不需要横向滚动。
- **改样式只需要看 `<style>` 一处**：只有一套主题、一个断点（`min-width:900px` 时右侧常驻历史面板）。
- **改了页面记得给 `sw.js` 的 `VERSION` 加 1**，否则老用户会一直吃缓存。

## 发布到 GitHub Pages

Settings → Pages → Source 选 **Deploy from a branch**，分支 `main`，目录 `/ (root)`。所有路径都是相对的，放在 `/<仓库名>/` 子路径下也能正常工作。
